# fmanager — TUI файловый менеджер на C

Полноценный консольный файловый менеджер в стиле Midnight Commander.
Написан на чистом C (C11) с использованием POSIX API и ncurses.

## Возможности

- **Две панели** — левая (текущая папка) и правая (`$HOME`), переключение через `Tab`.
- **Навигация** — стрелки, `Enter` (войти), `Backspace` (на уровень вверх).
- **Файловые операции** — копирование, перемещение, переименование, создание папок, удаление.
- **Просмотр и редактирование** — `v` открывает файл через `$PAGER`, `e` — через `$EDITOR`.
- **Сканирование `/` в кэш** — клавиша `s` собирает размеры всех директорий.
  После этого размер любой папки показывается мгновенно из кэша.
- **Диагностика** — снизу статус-бар: сколько файлов прочитано, сколько ошибок, сколько каталогов без доступа.

```

┌─ /home/user ──────────────┬─ /home/user/Documents ──────┐
│ ..                        │ ..                          │
│ Documents/        4.2 MB  │ report.pdf         1.2 MB   │
│ Downloads/      128.0 MB  │ notes.txt           24 KB   │
│ photo.jpg          2.1 MB │ photos/             45 MB   │
└───────────────────────────┴─────────────────────────────┘
Files: 14203 | Cache: 3421 | Errors: 12 | No access: 5
h Help | r Rename | v View | e Edit | c Copy | m Move | n New | d Delete | s Scan | q Quit

```

## Зависимости

Нужен компилятор C и заголовки ncurses:

- **Debian / Ubuntu:** `sudo apt install build-essential libncurses-dev`
- **Fedora:** `sudo dnf install gcc make ncurses-devel`
- **Arch:** `sudo pacman -S base-devel ncurses`

## Сборка и запуск

```bash
make          # собрать
make run      # собрать и запустить
make clean    # удалить объектные файлы и бинарник
```

Или вручную:

```
gcc -Wall -Wextra -O2 -std=c11 src/*.c -o fmanager -lncurses
./fmanager
```

## Управление

| Клавиша ↕▾ | Действие ↕▾ |
|---|---|
| −`h` | Справка |
| −`r` | Переименовать |
| −`v` | Просмотреть файл (`$PAGER`) |
| −`e` | Редактировать (`$EDITOR`, `vi`) |
| −`c` | Копировать в другую панель |
| −`m` | Переместить в другую панель |
| −`n` | Создать папку |
| −`d` | Удалить (с подтверждением) |
| −`s` | Сканировать `/` и заполнить кэш |
| −`q` | Выход |
| −`Tab` | Переключить активную панель |
| −`↑` `↓` | Движение по списку |
| −`Enter` | Войти в папку / открыть файл |
| −`Backspace` | Выйти на уровень вверх |
| −`Home` / `End` | В начало / в конец списка |
⚙

В диалогах подтверждения: `y` — да, `n` или `Esc` — отмена.

## Структура проекта

```
fmanager/
├── Makefile
├── README.md
└── src/
    ├── main.c      — точка входа, обработка SIGINT
    ├── ui.c / ui.h — TUI: две панели, отрисовка, клавиши, диалоги
    ├── fs.c / fs.h — файловые операции (POSIX)
    ├── scan.c / scan.h — рекурсивный обход и подсчёт размеров
    └── cache.c / cache.h — кэш размеров директорий
```

## Как это работает

- **Рекурсивный обход** (`scan_dir_weight`) использует `lstat`, а не `stat`,
чтобы не следовать по симлинкам. Это защищает от зацикливания на `/proc` и `/sys`.
- **Кэш** — простой динамический массив пар `(путь, размер)`. Растёт удвоением.
Поиск линейный — для пет-проекта этого достаточно.
- **Копирование** идёт буфером 64 КБ через `read`/`write`.
- **Перемещение** сначала пытается `rename()`. Если ядро возвращает `EXDEV`
(файл на другой файловой системе) — делает копирование + удаление источника.
- **Удаление** рекурсивно идёт по дереву и вызывает `unlink` для файлов,
`rmdir` для каталогов. Запрещено удаление корня `/`.

## Ограничения

- Только Linux (POSIX). Под Windows — отдельный `main.c`, использующий `_wopendir` и `wchar_t`.
- Нет сетевых операций (FTP/SFTP), работы с архивами, поиска по маске.
Это возможные следующие итерации.
