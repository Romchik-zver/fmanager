# fmanager

Однопанельный TUI-файловый менеджер на C11 и ncurses. Ходит по каталогам,
копирует, перемещает, удаляет, ищет рекурсивно и один раз сканирует `/`,
чтобы потом отдавать размеры папок из кэша без повторного обхода.

## Как выглядит

```

┌─ /home/user ────────────────────────────────────────┐
│ + Documents/                              4.2 MB / │
│   Downloads/                            128.0 MB / │
│   notes.txt                                24 KB   │
│   report.pdf                              1.2 MB   │
└─────────────────────────────────────────────────────┘
Files: 14203 | Cache: 3421 | Errors: 12 | No access: 5 | Sort: name | -rw-r--r-- notes.txt
h Help | / Search | r Rename | v View | e Edit | c Copy | m Move | n Newdir | f File | d Delete | s Scan | q Quit

```

## Что нужно

- Linux (или другая POSIX-система), компилятор с C11 и ncurses с
  поддержкой широких символов.
- Debian/Ubuntu: `sudo apt install build-essential libncurses-dev`
- Fedora: `sudo dnf install gcc make ncurses-devel`
- Arch: `sudo pacman -S base-devel ncurses`

## Сборка

```sh
gcc -Wall -Wextra -O2 -std=c11 src/*.c -o fmanager -lncurses
./fmanager
```

Для AppImage есть `build-appimage.sh`. Ему нужны `nix` (оттуда тянется
`libncursesw.so.6`), `patchelf`, `wget` и `mksquashfs`:

```
./build-appimage.sh
# получится fmanager-x86_64.AppImage
```

## Управление

| Клавиша ↕▾ | Действие ↕▾ |
|---|---|
| −`↑` / `↓` | Двигаться по списку |
| `Home` / `End` | В начало / в конец списка |
| `Enter` | Зайти в каталог или открыть файл на просмотр |
| `→` | Зайти в каталог |
| `←`, `Backspace` | Подняться на уровень вверх |
| `Space` | Пометить/снять пометку, курсор идёт вниз |
| `u` | Снять все пометки |
| `h` | Справка |
| `/` | Рекурсивный поиск (подстрока или маска `*.c`, `?`) |
| `r` | Переименовать |
| `v` | Открыть файл в просмотрщике |
| `e` | Открыть файл в редакторе |
| `c` | Копировать отмеченное (или текущее) в указанный каталог |
| `m` | Переместить отмеченное (или текущее) в указанный каталог |
| `n` | Создать каталог |
| `f` | Создать пустой файл |
| `d` | Удалить отмеченное (или текущее), спросит подтверждение |
| `p` | chmod (восьмеричное число, например `755`) |
| `s` | Запустить сканирование `/` в фоне, наполнить кэш |
| `S` | Переключить сортировку: name → size → time → ext |
| `:` | Выполнить команду шелла в текущем каталоге панели |
| `q` | Выйти |
⚙

В диалогах `Tab` — автодополнение пути, `Enter` — подтвердить, `Esc` —
отмена. При перезаписи в copy/move: `y` — перезаписать, `n` — пропустить,
`a` — перезаписать все, `c` — отменить.

## Просмотр и редактирование

Свои, внешние `$PAGER` и `$EDITOR` не вызываются. Подсветка синтаксиса
работает для C/C++/Rust/Go/JS/TS/Java/C# (`.c .h .cpp .cc .hpp .rs .go
.js .ts .java .cs`), Python (`.py`) и shell (`.sh .bash`).

- Просмотр: стрелки, `PgUp`/`PgDn`, `Home`/`End`, выход — `q` или `Esc`.
- Редактирование: обычный набор текста, `Enter` — новая строка,
`Backspace` — стереть символ, `Esc` — сохранить и выйти. Курсор всегда
в конце буфера.

## Настройка

Файл `~/.config/fmanager/fmanager.conf` создаётся сам при первом запуске.
Настраиваются цвета: `dir_fg/dir_bg`, `link_fg/link_bg`, `exec_fg/exec_bg`,
`status_fg/status_bg`, `header_fg/header_bg`, `key_fg/key_bg` и подсветка
синтаксиса `syn_key_fg`, `syn_str_fg`, `syn_com_fg`. Доступные имена:
`black red green yellow blue magenta cyan white default`.

Последний каталог и позиция курсора, а также кэш размеров лежат в
`~/.cache/fmanager.state` и `~/.cache/fmanager.cache`.

## Внутреннее устройство

- Обход идёт через `lstat`, а не `stat` — симлинки не разворачиваются,
зацикливание невозможно.
- Размер файла — `st_blocks * 512` (сколько реально занято на диске),
при нуле берётся `st_size`.
- Фоновое сканирование `/` живёт в отдельном потоке (`pthread`), пишет
в `cache_put`, потом `cache_sort` и бинарный поиск через `bsearch`.
- При сканировании и поиске пропускаются `/proc`, `/sys`, `/dev`, `/run`.
- Копирование — буфер на 64 КБ, `read`/`write`. Перемещение сначала
пробует `rename`, при `EXDEV` — копирование и удаление источника.
- Удалить корень `/` нельзя: `fs_delete` это проверяет.

## Что не сделано

- Работает только на POSIX/Linux.
- Нет архивов, сети и второй панели (панель одна, `Tab` не обрабатывается).
- `s` всегда сканирует именно `/`, независимо от того, где стоит панель.
- Редактор принимает только ASCII с клавиатуры. UTF-8 в файле отображается
правильно, `Backspace` удаляет целый codepoint, но ввести кириллицу
с клавиатуры не получится.
- Проверка существования файла назначения в copy/move идёт через `stat`,
то есть по симлинкам.

## Структура

```
fmanager/
├── build-appimage.sh    — сборка AppImage (nix + patchelf + mksquashfs)
├── README.md
└── src/
    ├── main.c           — вход, SIGINT, setlocale
    ├── ui.c / ui.h      — панель, отрисовка, клавиши, поиск, копирование
    ├── fs.c / fs.h      — POSIX-операции над файлами
    ├── scan.c / scan.h  — обход дерева, фоновое сканирование
    ├── cache.c / cache.h — массив (путь, размер) и его сохранение
    ├── dialogs.c / .h   — окна ввода, подтверждения, справки
    ├── theme.c / .h     — чтение конфига и init_pair
    └── viewer.c / .h    — встроенный просмотрщик и редактор с подсветкой
```
